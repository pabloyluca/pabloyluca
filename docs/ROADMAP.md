# Plan de implementación
| Fase | Resultado y validación previstos |
|---|---|
| 0. Discovery | Identificar el repositorio, las conexiones y los ocho originales. Registrar bloqueos y dependencias. |
| 1. Diseño | Extraer los activos, aplicar los colores de marca y construir layouts responsivos. |
| 2. Tienda | Probar personalización, carrito persistente, dirección o recolección y seguimiento privado. |
| 3. Persistencia | Usar migraciones PostgreSQL, roles de servidor y contenido administrable. |
| 4. Comercio | Reservar stock y capacidad en una transacción. Verificar y conciliar el pago antes de producir. |
| 5. Cocina | Producir una unidad por pizza. Recuperar tiempos tras recargar y confirmar el despacho. |
| 6. Notificaciones | Encolar avisos en la transacción y enviarlos con un proceso independiente e idempotente. |
| 7. ERP | Recalcular recetas, congelar costos históricos y distinguir compras de consumos. |
| 8. LU | Compartir herramientas deterministas y dejar el transporte de WhatsApp pendiente de autorización. |
| 9. QA | Ejecutar pruebas de dominio y navegador local y documentar los límites del ensayo. |
